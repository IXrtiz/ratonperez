# Casa del Ratón Pérez

Página web 3D: el Ratón Pérez sale por su puertita según el botón que se toque (Saludar, Recibir correo, Aprobación de cepillado), con voz sintética y subtítulos.

- `index.html`: la página (three.js desde jsDelivr).
- `raton_casa.json`: escena y animaciones en formato glTF.

Publicar: Settings → Pages → Deploy from a branch → `main` / `(root)`.
